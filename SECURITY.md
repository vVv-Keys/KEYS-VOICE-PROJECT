# Security policy

This is a private voice-identity project. Treat raw recordings and derived voice
models as sensitive biometric-like material.

Do not commit:

- account credentials, session cookies, API keys, or BandLab/Suno tokens;
- private collaboration links;
- legal names or contact details not already approved for publication;
- raw audio, checkpoints, or stems without an explicit storage decision;
- voice recordings belonging to another performer without documented consent.

If sensitive data is committed, stop sharing the repository, rotate any exposed
credential, remove the material from Git history, and document the incident.
